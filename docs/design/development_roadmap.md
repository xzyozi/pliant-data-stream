# 開発ロードマップ & タスク一覧

本ドキュメントでは、初期設計（`feature/core-pipeline`）に続き、各機能実装ブランチで対応するタスクとブランチ名の設計をまとめています。

---

## 🗺️ 今後の開発ブランチ設計

基本設計書に定義された各コンポーネントを、以下の3つの機能ブランチに分割して開発を進めます。

### 1. CSV/TSV パース & 自動判定機能
* **ブランチ名**: `feature/parser-auto-detect`
* **対象ファイル**: `src/sort_engine/reader.py` などの更新
* **主要タスク**:
  - [x] `csv.Sniffer` を用いた、カンマ/タブ区切りの自動判定処理の実装
  - [x] ダブルクォート内の改行やデリミタを正常に処理するセキュアパース処理の検証
  - [x] 日付・数値などの自動型推論関数の実装（比較処理の最適化用）
  - [x] 対応する単体テストの追加

---

### 2. 外部マージソート (Core Sorter) 機能
* **ブランチ名**: `feature/external-sort`
* **対象ファイル**: `src/sort_engine/sorter.py` などの更新
* **主要タスク**:
  - [ ] 指定された `chunk_size` に合わせてデータを分割し、メモリ上での一時ソートを実行する処理の実装
  - [ ] 一時ファイルをディスク（`tempfile`）に退避（Spilling）する処理の実装
  - [ ] `heapq.merge` を用いた、退避済み一時ファイルのK-wayマージソート処理の実装
  - [ ] 外部スクリプトからソートキー評価関数を動的に読み込むカスタム重み付け機能の実装
  - [ ] 大容量データ（数百万行）を想定したダミーデータでの結合テストの追加

---

### 3. SQLite 永続化 (SQLite Writer) 機能
* **ブランチ名**: `feature/sqlite-writer`
* **対象ファイル**: `src/sort_engine/writer.py` などの更新
* **主要タスク**:
  - [ ] `sqlite3` モジュールを用いた、データ書き出し先の接続制御処理の実装
  - [ ] 初回行などのヘッダー情報を元にした、SQLiteテーブルの自動・動的生成処理の実装
  - [ ] 大容量データを効率よく高速インポートする一括インサート処理の実装
  - [ ] インメモリおよびファイルベースのデータベース双方への永続化テストの追加
